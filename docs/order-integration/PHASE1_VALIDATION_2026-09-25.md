# 一期改动与验证记录（2026-09-25）

## 已实现

- 单进程原子占机、无容量时等待、等待可取消；6 分钟期限。
- 可用设备查询，在线/游戏匹配/占用过滤与预计截止时间。

- 对接接口取消密钥要求；原管理台认证保留。本机测试模式仍仅允许 loopback。
